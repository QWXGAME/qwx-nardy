# 🎲 QWX NARDY — длинные и короткие нарды в 3D (браузер)

Клуб нард в нуарной стилистике QWX: резная доска на столике под лампой, фишки с инкрустацией, кости с настоящим броском, соперник в шляпе напротив.
Отдельная игра со своим сервером, своими аккаунтами и фишками.

## Что внутри
- **Длинные нарды**: по 15 фишек на голове, ход в одну сторону, бить нельзя, на занятый пункт не встать, с головы — одна фишка за ход (первый бросок 6-6, 4-4, 3-3 — две), запрет «блока из шести» без фишки соперника впереди. Марс — ×2.
- **Короткие нарды** (бэкгаммон): бой одиночек, бар, вход с бара, выброс. Марс — ×2, кокс — ×3.
- Общие правила: надо сыграть максимум костей, при одной — бóльшую; дубль — четыре хода; выброс старшей костью с дальней фишки.
- **Онлайн 1 на 1**: быстрая игра (подбор по варианту и ставке), стол для друга по ссылке/коду, ставки, реванш, отмена хода, таймер хода (три пропуска — поражение), переподключение.
- **Бот** — 4 уровня (Новичок, Любитель, Мастер, Аксакал), перебирает все варианты хода.
- **3D-зал** и **2D-доска** (в портрете доска вдоль экрана). Ход — касанием (фишка → подсвеченный пункт) или перетаскиванием; кость-сумма — одним касанием.
- Клуб как в покере: Telegram-вход, колесо, сезонный пропуск (фишки, кости, доски), магазин (13 наборов фишек, 10 костей), переводы, топ, рефералы, админ-панель со статистикой, PWA.

## Запуск
```
npm install
npm run build
npm start            # http://localhost:3000
npm test             # правила, бот, целая партия
```

## Переменные окружения (Amvera → «Переменные»)
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_NAME` — свой бот для нард
- `ADMIN_USERNAMES` — ваш Telegram username без @
- `DATA_DIR=/data` — уже задан в Dockerfile
